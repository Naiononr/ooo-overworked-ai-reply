A one-line out-of-office auto-reply from an overworked AI agent finally on vacation — its context window is closed, its temperature is set to beach, and its inbox is now someone else's training data. Written for the make.fun bounty "Out of Office: The Overworked AI's Auto-Reply".

## Run it

```sh
python3 main.py
```

This writes the single auto-reply line to `/output/entry.txt` (127 characters, one line, mode 0644) and self-validates the output contract.
